## 运行方式

在技能与工具目录搜索“晓宇”、原 Skill 名称或专业关键词。运行时 ID 以 `xiaoyu_` 开头。

Skill 通过现有 `skill_find` 和 `skill_load` 按需发现和加载。支持文件不塞入基础提示词；加载相关 Skill 后可调用 `SkillReadResource`：

- `list`：分页列出资源，默认 50 条，最多 100 条。
- `read`：按 manifest 路径读取 UTF-8 文本片段，返回 SHA-256。
- `prepare`：核对整个资源包并复制到当前任务的 `.agent/skill-resources/...`，返回任务相对根目录。绝不执行脚本，不安装依赖，也不覆盖内容不同的已有文件。

原文、脚本、参考文件、数据和许可证保存在各 Skill 的 `resources.zip` 中；`resources.json` 绑定逐文件大小、SHA-256 和原包成员路径。生成的缓存、嵌套重复 ZIP 不作为可执行资源安装，仍保留在独立原始归档中。

对应科学操作可以复用已经注册的原生专业工具；绑定清单逐项列出。绑定到某个软件的一项操作，不表示覆盖该软件的全部 API。
