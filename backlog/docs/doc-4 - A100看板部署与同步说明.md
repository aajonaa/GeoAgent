# A100 项目看板：运行与同步约定

这是独立的 Backlog.md 项目管理服务，任务管理不进入 LangGraph。

## 目录与服务

- A100 管理快照目录：/data/wangjian/geoagent-project-board
- 用户服务：geoagent-project-board.service
- 依赖：backlog.md 1.53.0；独立安装，不改 Agent Python 环境。
- 服务器监听：127.0.0.1:6420
- 经当前双跳 SSH 访问：http://127.0.0.1:16420/board
- 本机原 6420 是旧的独立副本，不代表服务器状态。
- .source-revision 记录同步所用的完整 Git 提交；看板编辑后文件可能与该基线不同。

~~~bash
systemctl --user start geoagent-project-board.service
systemctl --user stop geoagent-project-board.service
journalctl --user -u geoagent-project-board.service -n 60
~~~

服务配置自带故障重启；退出登录或重启后的持续运行取决于现有 user-manager / linger 配置。本次不修改管理员级配置。

## 本地访问

A100 6420 经跳板机转发到跳板机本地 16420，再转发到 Windows 本地 16420。SSH 隧道未设置自动重连或开机启动。不要把无登录的看板暴露到公网或局域网。

## 同步规则

本次按用户授权提交管理文件到 GitHub，并将相同提交的管理快照发送到 A100；不是持续自动同步。

日常优先使用 A100 看板编辑。后续提交前先取回服务器最新记录，与仓库比较合并，再提交和推送。禁止用本机旧副本覆盖服务器新改动。不要同时在两个看板编辑同一任务。

服务器目录是管理文件快照，不是完整源码 checkout。GeoAgent 运行时和已有部署保持原样。A100 不保存 GitHub Token。

## 版本记录

管理文件提交不代表 Agent 重新部署或验收。历史基线与验收材料仍按原文档标注。
