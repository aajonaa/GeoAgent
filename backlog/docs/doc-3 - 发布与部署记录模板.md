# 发布与部署记录模板

创建新版本文档时填写；未执行的项目保留“未执行”。Done 不代表所有环境已上线。

## 版本身份

- 版本 / 候选版本：
- 源码完整 commit SHA：
- 来源分支 / PR：
- 关联任务：
- 构建 ID / 构建包哈希：
- 记录时间及时区：

## 变更说明

- 新增：
- 修复：
- 移除：
- 不兼容变更：
- 依赖 / 配置 / 数据库 / 数据迁移：

## 验收证据

| 检查项 | 状态 | 报告 / 运行 ID | 对应 commit 或构建 |
| --- | --- | --- | --- |
| 独立工具调用 / 注册 | 未执行 | | |
| 回归测试 | 未执行 | | |
| 浏览器交互与产物 | 未执行 | | |
| LangSmith 云端记录 | 未执行 | | |
| 安全、账号与文件隔离 | 未执行 | | |

- 失败或跳过的条目及原因：
- 不属于此次验收范围的项目：
- 数据是真实还是合成；使用许可与出处：

## 发布与部署

- 代码实现状态：
- 已验证范围：
- tag / Release 状态及链接：
- 部署环境：
- 部署时间：
- 运行时实际 build / commit：
- 叠加层（如仍存在）：
- 回滚目标及方法：
- 已知风险：

提交、发布和部署分别记录。尚未检查的项目不填“通过”。不写入凭证。
